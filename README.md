# Game Evaluation & Tier List Hub

A centralized graphical launcher and control panel designed to evaluate video games and visualize them on a sleek, interactive tier list board. By consolidating separate modules into a unified Tkinter codebase using tk.Toplevel windows, the entire suite runs within a single process and compiles effortlessly into a single executable file (.exe or Linux binary).

The central management hub offers a single point of entry for user authentication, profile status management, and seamless switching between sub-applications. Within the game tier list calculator, users can rate games using 5 core criteria with custom weight multipliers: Gameplay (4.0x), Graphics (2.0x), Storyline (3.0x), Music (1.5x), and Hardware/Optimization (1.5x). The calculator also implements smart personal preference constraints, ensuring that games with low personal scores are automatically capped and cannot reach the prestigious S or A tiers. 

The visual tier list board dynamically maps logged game assets into responsive rows ranging from S to F tier. It features automated asset fetching, which automatically searches for and downloads high-resolution game cover art using a specialized integration with Zyte API and DuckDuckGo API. Smart local image caching is included to minimize network overhead and ensure near-instantaneous board rendering. Additionally, a secure right-click context menu is available for direct database record deletion on your own profile, and the board fully supports exploring other public user directories.

The application is built on Python 3 using the native Tkinter GUI library for lightweight, cross-platform compatibility. Running the application from source requires installing the Pillow (PIL) package for image processing and resizing, as well as the requests package to manage network communication with the remote database API and Zyte services. The internal project dependencies include api_client, login_manager, user_directory, and game_explorer. To run the app from source, execute "pip install Pillow requests" followed by "python main_hub.py". Because all tools are now properly modularized into Python classes rather than external sub-processes, you can package the entire suite into a single file using PyInstaller by running the command "pyinstaller --onefile --windowed main_hub.py". The "--onefile" flag bundles everything into a single, portable executable file, while the "--windowed" flag hides the background terminal console when running the GUI application. During runtime, the application maintains a local ecosystem consisting of the "image_cache/" directory, where downloaded game cover arts are stored in .png format, and the "games_tier_list.json" file, which serves as a local backup tracking your entries while primary synchronization is handled remotely via api_client.
